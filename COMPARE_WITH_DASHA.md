# Сверка compas_custody_charges с таблицей Даши

Сравнивались заключения: у Даши `individual_custody_timeline_rfm.csv` (18 668 строк, одна строка = заключение), у нас `compas_custody_charges` (22 552 заключения, строки-обвинения свёрнуты до заключений). Ключ: `id` + `in_custody` + `out_custody`; у Даши `id` найден по имени и дате (см. DATA_EXPLAINED.md).

## Итог

| | заключений |
|---|---|
| есть в обеих таблицах | 17 472 |
| только у Даши | 1 196 (594 без даты + 602 с датой) |
| только у нас | 5 080 |

Главная причина: **Даша брала заключения не из compas.db, а из файла ProPublica `cox-violent-parsed.csv`** (его столбцы `in_custody`/`out_custody`) плюс заключение по делу COMPAS (`c_jail_in`/`c_jail_out`). Этот файл ProPublica строила для своей модели выживаемости: в нём только люди из её выборки и только заключения внутри её окна наблюдения. Мы берём все заключения из `jailhistory`/`prisonhistory` с 2013 года.

Формулы одинаковые; расхождения возникают только потому, что у человека в цепочке другие заключения. Если у нас есть заключение до заключения COMPAS, сдвигается номер (`custody_num`), меняются интервал до предыдущего и суммы длительностей. Если у нас есть заключение после конца окна ProPublica, у Даши последнее заключение получает `event = 0`, а у нас 1. Полностью одинаковый список заключений у 7 688 из 10 406 общих людей.

## Обвинения

У Даши `c_charge_degree`/`c_charge_desc` — одно обвинение по делу COMPAS, повторённое во всех заключениях человека. У нас — каждое обвинение своего заключения. Обвинение Даши находится среди наших обвинений того же заключения в 80% случаев для первого заключения (дело COMPAS) и в 42% для остальных: в остальных заключениях у человека другие дела.
