# compas_custody_charges: таблица напрямую из compas.db

Файлы: `compas_custody_charges.csv` / `.xlsx`, код: `build_from_compas_db.py`.
Запуск: `python build_from_compas_db.py compas.db .` из этой папки, или ноутбук `build_compas_custody_charges.ipynb` (база открывается только на чтение).

**Одна строка = одно обвинение внутри одного заключения.** Столбцы те же, что у Даши, `name` заменён на `id` = `person_id` из `casearrest` (он же `people.id`). В конце добавлены: `charge_num` (номер обвинения в заключении, 0 — не найдено), `n_charges`, `charge_category`, `charge_source`, `case_number`, `custody_source` (jail / prison).

## Откуда что берётся

| что | таблица compas.db |
|---|---|
| люди (`id`) | все `person_id` из `casearrest` |
| `age`, `sex`, `race` | `people` |
| заключения (`in_custody`, `out_custody`) | `jailhistory` + `prisonhistory`, вход с 2013-01-01 |
| обвинения (`c_charge_degree`, `c_charge_desc`) | `charge` по делам из `casearrest`, арестованным в ±1 день от входа; иначе по дате преступления (7 дней до входа); иначе последнее дело за 365 дней (`charge_source`) |

Производные столбцы считаются по `id` формулами Даши: `time_to_last_custody` = вход − предыдущий вход, `time_since_last_arrest` = вход − предыдущий выход, `time_to_future_arrest` = следующий вход − вход, `event` = 1, если есть следующее заключение, `curr_dur_custody` = выход − вход, `sum_dur_custody` / `average_dur_custody` — сумма и среднее длительностей предыдущих заключений, `all_future_*` — списки будущих заключений.

## Особенности данных

- Берутся **все** заключения из `jailhistory`/`prisonhistory` с 2013 года: 22 552 заключения у 10 580 человек. Ещё 383 человека из `casearrest` без заключений с 2013 года в таблицу не попадают.
- Записи `prisonhistory` до 2013 года не берутся: `jailhistory` в базе начинается с 2013-01-01, и ранние тюремные сроки дали бы ложные многолетние промежутки.
- Переход из jail в prison в тот же день записан двумя заключениями (`time_since_last_arrest` = 0, таких 863), как в источнике. Вторая строка — это приговор по тому же делу, а не новый арест.
- `out_custody = 2020-01-01` — заглушка базы «ещё в заключении» (661 заключение).

## Цифры

- 65 363 строки, 22 552 заключения, 10 580 человек.
- Обвинения найдены: по аресту — 20 368 заключений, по дате преступления — 71, по прошлому делу — 1 335, не найдены — 778.
- Заключений на человека: 1 — 5 220, 2 — 2 338, 3 — 1 364, 4 — 774, дальше хвост.
