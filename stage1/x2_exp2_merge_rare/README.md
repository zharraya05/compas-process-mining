# Эксперимент 2. Слить редкие OldCase

Состояния «OldCase: X» с числом событий меньше 300 объединены в «OldCase: Other». Проверяет, мешают ли редкие состояния.

Вариант «категории × 2», вход: таблица stage0 (`../../stage0 - data/out/compas_custody_charges.csv`). Запуск: открыть `x2_exp2_merge_rare.ipynb`, Run All (общий код в `x2_common.py`).

Папка `out/`: журнал событий, `log_stats.csv`, `model_quality.csv` (fitness/precision на train и test, TBR), `compare_with_oldcase_x2.csv`, рисунки DFG и сети Петри HM.
