# Эксперимент 1. Одно событие на заключение

От каждого заключения остаётся одна, самая тяжёлая категория (Justice только если других нет). Проверяет, сколько precision теряется из-за цепочек внутри заключения.

Вариант «категории × 2», вход: таблица stage0 (`../../stage0 - data/out/compas_custody_charges.csv`). Запуск: открыть `x2_exp1_one_event.ipynb`, Run All (общий код в `x2_common.py`).

Папка `out/`: журнал событий, `log_stats.csv`, `model_quality.csv` (fitness/precision на train и test, TBR), `compare_with_oldcase_x2.csv`, рисунки DFG и сети Петри HM.
