# Архив: время на дугах DFG «от входа до входа»

Версия ноутбука `stage1_categories_x2.ipynb` до перехода на время на свободе (10.10.2026).
Время на дугах DFG = `in_custody` следующего события − `in_custody` текущего, то есть срок в заключении
плюс время на свободе (медиана по переходам между заключениями — 157 дней).
В основной версии (папкой выше) время = выход → следующий вход (время на свободе, медиана 124 дня).

Всё остальное то же: вариант «категории × 2», категории одного заключения упорядочены по тяжести обвинения.
Запуск: открыть ноутбук из этой папки, *Run All*; вход — `jupyter lab\stage0 - data\out\compas_custody_charges.csv`
(на три уровня выше), результаты пишутся в `out\` этой папки. Главный рисунок версии —
`out\figures\dfg_performance_paths30.png`.
