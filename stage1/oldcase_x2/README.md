# Этап 1. Вариант «категории × 2» (oldcase_x2)

Ноутбук `stage1_categories_x2.ipynb` — шаги 2–4 плана для варианта, где у каждой категории преступления `X`
есть двойник `OldCase: X` (повторное заключение по делу, которое уже было у человека раньше):

2. журнал событий: `case:concept:name` = `id`, `concept:name` = категория или `OldCase: категория`,
   `time:timestamp` = `in_custody`; одна строка = одна категория в одном заключении; Justice отдельным шагом;
   последнее заключение человека цензурировано (без END);
3. статистика и сравнение с вариантами «все новые», OldCase и «без OldCase» (все четыре строятся одной функцией);
4. PM4Py: DFG (частоты и времена), Heuristics Miner, Inductive Miner → сети Петри; один общий граф по всем людям.

**Смешанное заключение (выбор по умолчанию):** новые обвинения дают `X`, старые — `OldCase: X`, ничего не
отбрасывается. Альтернатива (только новые) включается двумя строками в функции `build`.

## Запуск

Окружение `D:\Git\diploma\.venv` (pm4py 2.7.23.9), Graphviz `D:\Graphviz\bin`. Открыть ноутбук в Jupyter Lab из
этой папки и выполнить все ячейки (~1–2 мин, плюс ~1 мин на Excel). Вход — таблица этапа 0:
`jupyter lab\stage0 - data\out\compas_custody_charges.csv` (в репозитории — `stage0-data/compas_custody_charges.csv`).
`RUN_EVAL = True` пересчитывает fitness/precision (~3 мин), иначе берётся `out/model_quality_x2.csv`.
