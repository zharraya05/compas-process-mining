# stage1/all_new

Этап 1, вариант «все обвинения новые». Дата: 10.10.2026.

## Как открыть

```
D:\Git\diploma\.venv\Scripts\activate
cd "D:\diploma\jupyter lab"
jupyter lab
```

Открыть `stage1/all_new/stage1_all_new.ipynb`, *Run → Run All Cells* (около минуты). Входные данные — таблица этапа 0 `../../stage0 - data/out/compas_custody_charges.csv`. Ноутбук проверен: пересчёт совпадает с сохранёнными `log_info.csv`, `event_log.csv` и `transition_probs.csv` (разница 0).

Флаги в шаге 0: `RUN_MODELS` (сети Петри IM / HM / DFG, меньше минуты), `RUN_EVAL` (fitness/precision HM dep 0.9, несколько минут; для всех моделей часы, поэтому таблица качества берётся из сохранённого файла).

  Форма Вейбулла по состояниям ρ = 0.58–0.80; лучшие распределения — логнормальное и лог-логистическое.
